# 学習AI（相手AI）

対戦卓の相手AIに「学習AI」を足すためのフォルダです。

- `net.bin` … 自己対戦で学習したネットの重み（無い時は重みなしの先読みだけで動きます）
- `net.json` … 重みの情報（世代など）

AI 本体（Rust のルールエンジンと先読み）は WebAssembly にして index.html の `<script id="dmaz">` に入っています。
ソースと学習の仕組みは `alphazero-engine` ブランチの `alphazero/` にあります。

使われるのは、相手が簡易AIで、両方のデッキがリースバイク・ハッスル・キャッスル・ジョーカーズのカードだけでできている時です。
ツール欄の「学習AI：ON/OFF」で切り替えられます。
