# dmengine（学習用デュエマ・ルールエンジン）

2026-11-24 作成。一平さんの学習用3デッキ（リースバイク・ハッスル・キャッスル・ジョーカーズ）の40種類だけを実装した、画面なしの高速エンジンです。対戦卓（patches.js）とは別物で、対戦卓は変更しません。

- 言語：Rust（外部ライブラリなし）
- `cargo build --release` → `target/release/bench 10000 stats`（ランダム同士で 1万局、効果ごとの使用回数を表示）
- すべての判断は `Decision`（選択肢の一覧）として外に出し、`step(i)` で進めます。先読み（ISMCTS）や学習（自己対戦）は、この一覧から選ぶ形でつなぎます。

### 近似（新カード）
- 進化エレメントをシールド化する時は、全部を1つのシールドに重ねる（裁定メモの不明点1。316.3・113.2 から）
- カンツォーネが破壊された時、NEO・進化クリーチャーがいなければ、下にあったカードは表向きの1つのシールドになる（墓地に残す選択はしない）
- エバーラストのマナ武装5は、シールドが3つ以上あり、離れるのがコスト5以上のクリーチャーで、相手の効果・バトル・破壊で離れる時に自動で使う（シールドが1つの時は使わない＝不明点2）
- シネラリアのウルトラ・セイバーは、コスト4以上のジャイアントが相手の効果・バトル・破壊で離れる時に自動で使う
- ゴルギーオージャーの軽減は、進化元のエレメントに含まれるカードをすべて数える（不明点3、31794）。下限3
- TAKASUGI を D・D・D で攻撃中のクリーチャーの上に置いたら、攻撃を続ける（不明点4、レッドゾーンと同じ）
- グリーン・グランドクロスの軽減は、使うかどうかを出し方（how の 8 のビット）で選ぶ。自分のメインステップの召喚だけ。ターンの終わりのドローは、山札が5枚より多ければ自動で引く
- 複数のG城の置換が重なる場面は無い（ブレイクを置き換えるのはセイント・キャッスルだけ）＝不明点6
- エモーショナル・ハードコアの名前は、バトルゾーンにあるクリーチャーの名前から選ぶ。オラクルの「選ばれない」は、デッキに他のオラクルがいないので入れていない
- ウィリデ・アカネの代替コストに、グランドクロスの軽減は使える（45560）。ウィリデの能力で手札から出す時は、進化しないで出す
- 出せない状況（一音の妖精・マンハッタン・5000VT）で効果によって出そうとしたカードは墓地へ（S・トリガーは手札に残る）
- ザゼ・ゼーンの「相手クリーチャーをタップ」はチャクラと同じ扱い（次の相手のターンのはじめにアンタップしない）
